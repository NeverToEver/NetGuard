# NetGuard 更新说明

本文档记录 NetGuard 本轮界面优化、运行环境切换、macOS 打包与验证工作的主要变化。

## 1. 更新概述

本轮更新的重点是将项目运行方式统一为项目内虚拟环境，并继续完善 macOS 可执行应用交付流程。同时，图形界面参考 Wireshark 的信息密度和操作习惯进行了优化，修复窗口化显示时顶部按钮被挤压、显示不完整的问题。

更新后的项目仍保持原有核心能力：

- 枚举网卡并通过 `libpcap` / WinPcap / Npcap 抓包
- 支持 BPF 捕获过滤和界面显示过滤
- 展示数据包列表、协议详情、十六进制内容、告警和统计信息
- 支持 IDS 规则加载、告警导出和 macOS 应用包运行

## 2. UI 调整

### 2.1 工具栏布局优化

原顶部工具栏把网卡选择、Mac 映射、BPF 过滤、操作按钮和状态信息放在同一个网格中。窗口化或缩小窗口时，部分列会互相挤压，导致按钮显示不全。

本轮将顶部工具栏拆分为两个稳定区域：

- 左侧捕获设置区：`NetGuard Capture`、网卡选择、Mac 映射、Capture filter、应用映射、自动推断
- 右侧操作区：开始、停止、暂停、清空、导出告警、夜间模式和运行状态

右侧按钮改为两行紧凑排列，核心输入框保留横向伸缩能力，按钮采用固定宽度，从而降低窗口宽度变化时的布局风险。

### 2.2 Wireshark 风格信息密度

界面继续保持抓包分析工具常见的信息密度：

- 包列表占据主要空间
- 右侧展示 Packet details 与 Packet bytes
- 下方展示 Alerts 和 Statistics
- 顶部保留 Packets、速率、会话数和告警数等轻量指标

整体视觉使用浅色蓝灰工作台风格，并保留夜间模式切换。

## 3. 虚拟环境与启动方式

项目运行方式已调整为优先使用项目内 `.venv`：

```bash
/opt/homebrew/bin/python3.12 -m venv .venv
./.venv/bin/python -m pip install --upgrade pip
./.venv/bin/python -m pip install -e .
./scripts/run_netguard.sh
```

`scripts/check_interpreter.sh` 会优先检测：

- `NETGUARD_PYTHON` 指定的解释器
- 项目内 `.venv/bin/python`
- 常见 Homebrew Python 3.12 / 3.11 路径
- 系统可用的 `python3` / `python`

项目不依赖某个固定的本机 Python 发行版，只要求可用的 Python 3.11+ 解释器。

## 4. macOS 打包更新

macOS 打包脚本 `scripts/build_unix_app.py` 已兼容标准虚拟环境结构。由于 venv 的标准库和 Tkinter 组件可能位于 Homebrew Python 基础路径中，打包脚本现在会通过目标解释器实际导入 Tkinter 来判断支持情况，并把运行所需的 Tkinter、`_tkinter` 动态库、Tcl/Tk 资源目录复制到产物中。

本轮打包使用专门的 `.venv-build` 环境：

```bash
/opt/homebrew/bin/python3.12 -m venv --copies .venv-build
./.venv-build/bin/python scripts/build_unix_app.py --python-env .venv-build
```

生成产物包括：

- `dist/NetGuard`
- `dist/NetGuard-portable`
- `dist/NetGuard.app`

其中 `.venv-build/` 是本地构建环境，已加入 `.gitignore`，不会提交到仓库。

## 6. 验证结果

已完成以下验证：

```bash
PYTHONPYCACHEPREFIX=/tmp/netguard-pycache ./.venv/bin/python -m py_compile src/netguard/gui/main_ui.py scripts/build_unix_app.py
./.venv/bin/python -m pytest
./dist/NetGuard --list-devices
/usr/bin/codesign --verify --deep --strict --verbose=2 dist/NetGuard.app
```

验证结果：

- 单元测试通过：`12 passed`
- 打包入口可正常枚举 21 个网卡
- `dist/NetGuard.app` 签名校验通过
- `.app` 内置 Python 可导入 Tkinter，Tcl/Tk 版本为 `9.0.3`

## 7. 使用注意

macOS 双击 `dist/NetGuard.app` 时，系统可能弹出管理员授权窗口。该授权用于调整 `/dev/bpf*` 抓包设备权限，属于抓包工具在 macOS 上访问网络数据包的正常流程。

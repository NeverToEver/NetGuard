# 使用说明

## 启动

```bash
./scripts/run_netguard.sh
```

启动脚本会自动检测可用的 Python 3.11+ 解释器，优先使用 `NETGUARD_PYTHON`、项目内 `.venv/bin/python`、常见 Homebrew/Python 路径。如果没有找到合适解释器，会提示创建项目内环境。

打包后可运行：

```bash
sudo ./dist/NetGuard
```

## 图形界面

窗口分为四层：

- **菜单栏**：文件（打开/保存 pcap、导出告警、退出）、捕获（开始/停止/暂停/清空、应用推荐网卡）、
  视图（主题、聚焦显示过滤）、工具（测试发包、网段扫描、规则相关）、帮助（快捷键说明）。
- **顶栏**：左侧是品牌与抓包状态胶囊（空闲 / 抓包中 / 已暂停），右侧是主题切换按钮
  （在「跟随系统 → 浅色 → 深色」之间循环，与「视图 → 主题」菜单等价）。
- **左侧操作轨**：竖向排列的开始、停止、暂停、清空、打开、保存、导出、发包、扫描、规则。
  抓包进行中时「停止」会变成醒目的主操作色；暂停时「暂停」按钮转为琥珀色。
- **捕获工具条**：选择网卡、填写 BPF、套用模板；最右侧常驻显示丢弃与解析异常计数。
- **KPI 指标条**：数据包总数、包速率、吞吐量、活动会话、IDS 告警五张指标卡，
  各带一条迷你走势图；告警卡用红色竖条与红色数字突出。
- **显示过滤栏**：在当前已捕获列表内筛选，右侧胶囊显示「显示条数 / 总条数」。
- **数据包列表**：显示时间、源地址、目的地址、协议、长度和摘要；点击表头排序，再次点击切换升/降序。
  协议名按类型着色，带解析异常的包整行标红底。
- **数据包检视**：与列表并排，分「解析树」和「原始字节」两个标签页。
  解析树按帧 → 链路层 → 网络层 → 传输层 → 应用层逐级展开，前两层默认打开。
- **底部标签页**：告警、解析问题、流量统计、IDS 规则；标签标题带实时计数。
  告警表按严重度着色，并区分内置检测器与 IDS 规则命中。
- **底栏**：一行日志（点「展开」可拉到 7 行）与状态栏。

### 表格操作

- 右键菜单：复制摘要 / 复制整行 / 复制源→目的 / 复制解析详情 / 复制十六进制 /
  用摘要筛选 / 定位告警。
- `Ctrl+C` 复制选中数据包整行。
- 双击告警或解析问题条目，可跳转并选中对应的数据包行。
- 告警表可点表头按时间 / 级别 / 来源 / 信息排序，排序按语义（时间取真实时间戳、
  级别按高→低）而不是字符串字典序。新到的告警按到达顺序追加到表尾（表头箭头不会
  自动重排），再看排序结果时再点一次表头即可。

### 主题与布局记忆

- 视图 → 主题可切换浅色、深色或“跟随系统”。“跟随系统”会定期检测系统外观并自动切换。
- 窗口大小与位置、分隔条位置、列宽、排序状态、上次选择的网卡与过滤条件会自动保存到
  `~/.netguard_config.json`，下次启动恢复。
- 窗口最小尺寸为 1280×760；拖动窗口或分隔条时两侧窗格都会保留最小可用宽度，
  不会把「数据包检视」压成一条缝。

### 快捷键

`F5` 开始、`Shift+F5` 停止、`Ctrl+P` 暂停/恢复、`Ctrl+L` 清空、`Ctrl+O` 打开 pcap、
`Ctrl+S` 保存 pcap、`Ctrl+E` 导出告警、`Ctrl+F` 聚焦显示过滤、`Ctrl+Q` 退出、`F1` 快捷键说明。
对话框内 `Esc` 取消。

## 常用过滤

BPF 过滤会影响实际抓包范围：

```text
tcp
udp
port 53
port 80
tcp or udp
net 192.168.1.0/24
```

界面内“显示过滤”只过滤当前列表，不影响后台抓包。可输入协议、IP、端口、HTTP Host 或 DNS 域名关键字。

## IDS 规则

```text
alert tcp any any -> any 80 (content "GET"; msg "检测到 HTTP GET 请求";)
```

当前支持协议、源/目的端口、`content` 和 `msg`。规则修改后点击“加载规则”或重新开始监听。
内容规则除单包匹配外还会在 TCP 会话重组流中匹配，因此关键词被拆分到多个 TCP 段仍会命中。

## 攻击检测

除静态规则外，内置基于时间窗口的检测器，告警与规则命中一同显示在告警面板，
并可导出为 JSON。阈值可在构造时配置（`netguard.detection.DEFAULT_DETECTOR_CONFIG`）。

| 检测器 | 判据 | 默认阈值 |
| --- | --- | --- |
| SYN flood | 窗口内同一 (目的 IP, 端口) 的 SYN 数 | 5s / 100 |
| 端口扫描 | 窗口内同一源访问的不同目的端口数 | 10s / 20 |
| DNS 隧道 | 超长域名/标签，或同一后缀高频查询 | 10s / 50 |
| ICMP flood | 窗口内同一 (源, 目的) 的 ICMP Echo 数 | 5s / 100 |
| 暴力破解 | 窗口内发往 SSH/FTP/Telnet 等服务端口的 SYN 数 | 60s / 10 |

# 使用说明

## 启动

```bash
./scripts/run_netguard.sh
```

启动脚本会自动检测可用的 Python 3.11+ 解释器，优先使用 `NETGUARD_PYTHON`、项目内 `.venv/bin/python`、常见 Homebrew/Python 路径。如果没有找到合适解释器，会提示创建项目内环境。

打包后可运行：

```bash
sudo ./dist/NetGuard
```

## 图形界面

窗口自上而下分为：

- **菜单栏**：文件（打开/保存 pcap、导出告警、退出）、捕获（开始/停止/暂停/清空、应用推荐网卡）、
  视图（主题、聚焦显示过滤）、工具（测试发包、网段扫描、规则相关）、帮助（快捷键说明）。
- **工具栏**：选择网卡、填写 BPF、开始/停止监听、暂停刷新、清空、测试发包、网段扫描、
  打开/保存 pcap、导出告警、夜间模式。
- **显示过滤栏**：在当前已捕获列表内筛选；右侧显示数据包数、速率、会话数、告警数等指标。
- **数据包列表**：显示时间、源地址、目的地址、协议、长度和摘要；点击表头排序，再次点击切换升/降序。
- **右侧详情**：显示协议解析结果和原始数据十六进制内容。
- **底部区域**：IDS 告警、解析问题、实时统计和规则编辑框。
- **状态栏**：显示抓包状态（抓包中/已暂停/空闲）与后台任务进度。

### 表格操作

- 右键菜单：复制摘要 / 复制整行 / 复制源→目的 / 复制十六进制 / 用摘要筛选 / 定位告警。
- `Ctrl+C` 复制选中数据包整行。
- 双击告警或解析问题条目，可定位到对应数据包。

### 主题与布局记忆

- 视图 → 主题可切换浅色、深色或“跟随系统”。“跟随系统”会定期检测系统外观并自动切换。
- 窗口大小与位置、分隔条位置、列宽、排序状态、上次选择的网卡与过滤条件会自动保存到
  `~/.netguard_config.json`，下次启动恢复。

### 快捷键

`F5` 开始、`Shift+F5` 停止、`Ctrl+P` 暂停/恢复、`Ctrl+L` 清空、`Ctrl+O` 打开 pcap、
`Ctrl+S` 保存 pcap、`Ctrl+E` 导出告警、`Ctrl+F` 聚焦显示过滤、`Ctrl+Q` 退出、`F1` 快捷键说明。
对话框内 `Esc` 取消。

## 常用过滤

BPF 过滤会影响实际抓包范围：

```text
tcp
udp
port 53
port 80
tcp or udp
net 192.168.1.0/24
```

界面内“显示过滤”只过滤当前列表，不影响后台抓包。可输入协议、IP、端口、HTTP Host 或 DNS 域名关键字。

## IDS 规则

```text
alert tcp any any -> any 80 (content "GET"; msg "检测到 HTTP GET 请求";)
```

当前支持协议、源/目的端口、`content` 和 `msg`。规则修改后点击“加载规则”或重新开始监听。
内容规则除单包匹配外还会在 TCP 会话重组流中匹配，因此关键词被拆分到多个 TCP 段仍会命中。

## 攻击检测

除静态规则外，内置基于时间窗口的检测器，可发现 SYN flood、端口扫描、DNS 隧道等行为，
告警与规则命中一同显示在告警面板，并可导出为 JSON。
